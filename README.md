# 📊 算法可视化 — 考研数据结构

面向考研学生的 C/C++ 数据结构算法可视化网站，覆盖**7 个章节、31 个算法**，支持单步/连续播放、C++ 代码行高亮、自定义数据输入。

## 🌐 在线使用

**[xqian-a.github.io/algo-viz](https://xqian-a.github.io/algo-viz/)**

直接双击 `docs/index.html` 也可以离线使用（无需服务器）。

## 📚 算法目录

| 章节 | 算法数 | 内容 |
|------|:------:|------|
| 线性表 | 2 | 顺序表操作（增删查改）、链表操作（增删查改） |
| 栈和队列 | 3 | 栈操作、队列操作、循环队列 |
| 串 | 1 | KMP 算法（含 next 数组构建过程） |
| 树与二叉树 | 7 | 前/中/后/层次遍历、建立 BST、哈夫曼树、AVL 树 |
| 图 | 6 | DFS、BFS、Dijkstra、Prim、Kruskal、拓扑排序 |
| 查找 | 3 | 折半查找、BST 查找、散列表查找（均支持自定义查找目标） |
| 排序 | 9 | 冒泡、选择、插入、希尔、归并、快速、堆（树形）、计数、基数 |

## ✨ 功能特性

- 🎮 **单步运行 + 连续播放**：速度可调 (0.5× / 1× / 2× / 4×)
- 📝 **C++ 代码行高亮**：当前执行行自动高亮，关键行有中文注释
- 📐 **数据结构可视化**：Canvas2D 渲染数组、链表、栈、队列、树、图、散列表、字符串
- 🔍 **查找算法**：独立的查找目标输入框，不输入则使用默认值
- 📤 **上传自定义代码**：粘贴 C/C++ 代码，模板匹配自动识别算法类型
- 📖 **详细算法讲解**：每个算法含复杂度分析、考研要点、过程描述
- ↔️ **可拖拽面板**：代码面板可收起/展开/拖拽调整宽度，信息面板可向上拉大
- ⌨️ **键盘快捷键**：Space 播放/暂停，← → 步进，Home/End 首末步

## 🚀 本地开发

```bash
# 安装 Node.js（可选，仅开发用）
cd code_visualization

# 启动开发服务器（ES 模块版本）
python -m http.server 8080
# 访问 http://localhost:8080

# 打包为单文件（带 Prism 高亮）
python build.py
# 输出到 docs/index.html，双击即可打开
```

## 📁 项目结构

```
code_visualization/
├── index.html           # 开发入口（ES 模块）
├── docs/
│   └── index.html       # 构建产物，可直接打开 / GitHub Pages
├── css/                 # 样式（dark theme）
├── js/
│   ├── app.js           # 主入口
│   ├── core/            # 引擎：事件总线、注册表、步骤引擎、Canvas管理
│   ├── renderers/       # 8 种 Canvas 渲染器
│   ├── algorithms/      # 31 个算法（按 7 个章节分目录）
│   ├── ui/              # 界面组件
│   └── utils/           # 工具函数
└── build.py             # 打包脚本
```

## 🛠 技术栈

- 纯 HTML/CSS/JS，无框架
- Canvas2D 渲染
- Prism.js（代码高亮）
- Google Fonts（字体，加载失败不影响功能）
